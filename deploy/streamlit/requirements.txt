# Community Cloud only installs from a file literally named `requirements.txt`,
# and it searches the entrypoint's own directory before the repository root. So
# this file must live next to `streamlit_app.py`; it is picked up automatically
# and no "requirements file" setting exists in the deploy form. The repository
# root's `requirements.txt` stays the `lite` runtime set (see the Dockerfile).
#
# The heavy training extras (torchvision, sentence-transformers) are deliberately
# NOT included: the text/image features are already computed and committed under
# data/processed, so serving the companion needs CPU torch only.
